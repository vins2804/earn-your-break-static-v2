      Playbook

      How to Use This System and Stay Consistent

      Treat this app like an energy wallet: focused work earns break time, and unplanned breaks spend it. Your goal is to stay in control, not just run a timer.

      01

      Set Your Cycle

      Pick your ratio first. Start with 1:5 for stricter execution, or 1:3 for balanced pace.

      02

      Run Focus Block

      Press Start, work on one task only, then press Stop & Bank to convert focus into earned break.

      03

      Spend Break Intentionally

      Use Start Break only for intentional recovery. If bank goes negative, repay with focused work blocks.

      04

      Review AI Insights

      Check predicted focus, best cycle, and confidence daily. Use it to schedule deep work at your peak window.

      Cycle Cheat Sheet

      1:5Strict execution for high-priority deep work

      1:4Strong pace with moderate recovery

      1:3Balanced default for most days

      1:2Recovery-friendly during low-energy windows

      1:1Sustainable mode when avoiding burnout
